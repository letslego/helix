Leverages the full Helix stack

Workflows, AI Gateway, Sandbox, Connect, tools, and subagents — production agent infrastructure without gluing point solutions together.

Workflows

Checkpointed steps, park between messages, resume on delivery. Completed steps never re-run.

    WorkflowsDurable turns under .helix/workflows/
    AI GatewayRoute, fallback, and budget model calls
    SandboxIsolated FS, glob, grep, allowlisted bash
    ConnectBrokered MCP/OpenAPI auth — secrets stay out of prompts
    ToolsApprovals, streaming yields, toModelOutput
    SubagentsSpecialists with isolated sandboxes

      Scaffold

      npx @letslego/helix init my-agent
    2. 02

      Install & run

      cd my-agent && npm install && npx helix console
    3. 03

      Author capabilities

      Edit instructions.md, add tools under tools/, skills under skills/, and policies as JSON.
